# Contributing

Run `bash scripts/test.sh` and `python3 scripts/build.py` on macOS before proposing changes. Use synthetic fixtures only. Add behavior tests for parser changes, recovery, time handling and data retention. Do not add credentials, account screenshots, personal histories or generated binaries. Keep unsupported provider changes fail-closed and document their limits.

Contributions use the MIT license. Describe the behavior changed and the checks run. Do not claim independent-account or desktop-widget acceptance from compilation alone.
