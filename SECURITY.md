# Security

Do not include account identifiers, credentials, raw CLI output, usage snapshots or conversation content in public issues. Report reproducible failures with tool versions, macOS version and sanitized error categories only. A private vulnerability-reporting destination must be configured by the repository owner before publication.

The native companion launches the official provider CLIs installed on that Mac. Select trusted executables only. It is not sandboxed; the widget extension is sandboxed. No third-party binaries are bundled. The app's authentication checks are not a guarantee of provider authorization or future renewal.
